# Changelog

## 0.1.0

- Added engine-neutral navigation, snapshots, Agent Render Tree projection,
  native input planning, profiles, storage, network/cache, service workers,
  brokered credentials, audit/recovery, desktop shell, CLI, and SDK contracts.
- Added deterministic headless execution, query shaping, origin-scoped query
  filters, packaging metadata, and release validation gates.

This project is pre-1.0; protocol and persistence schemas remain subject to
the compatibility policy in `docs/release.md`.
